# subaco-shim の推移依存ピン留め（プレースホルダ）。
#
# 本ファイルはリリース時に subaco-shim リポジトリで `uv export` により生成し、
# テンプレートへ同梱する（e2b-code-interpreter 等の推移依存を完全固定する）。
# cube-shim ラッパーは、このファイルが存在すれば --with-requirements で使用する
# （コメントのみのプレースホルダでも無害。uv はコメント行を無視する）。
#
# 生成手順（リリース時・subaco-shim 側で実行。正典は subaco-shim の Justfile `just export-reqs`）:
#   uv export --no-dev --no-emit-project --format requirements-txt -o requirements-shim.txt
#
# subaco-shim は certifi を必須依存に持つため extras の指定は不要（hive とは異なる）。
# `--no-emit-project` はプロジェクト自身を除く（版の固定は `subaco-shim==<版>` 側で行うため）。
#
