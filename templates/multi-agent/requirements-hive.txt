# subaco-hive の推移依存ピン留め（プレースホルダ）。
#
# 本ファイルはリリース時に subaco-hive リポジトリで `uv export` により生成し、
# テンプレートへ同梱する（zvec・fastembed・mcp SDK 等の推移依存を完全固定する）。
# hive-mcp ラッパーは、このファイルが存在すれば --with-requirements で使用する
# （コメントのみのプレースホルダでも無害。uv はコメント行を無視する）。
#
# 生成手順（リリース時・subaco-hive 側で実行。正典は subaco-hive の Justfile `just export-reqs`）:
#   uv export --no-dev --extra all --no-emit-project --format requirements-txt -o requirements-hive.txt
#
# **`--extra all` は必須**: subaco-hive は依存をすべて optional-dependencies に置く設計のため、
# extras を指定しないと mcp SDK も zvec も requirements に載らず、MCP サーバーが
# 「mcp SDK が未導入です」で即終了する（dev fallback 経路で実測）。
# `--no-emit-project` はプロジェクト自身を除く（版の固定は `subaco-hive==<版>` 側で行うため）。
#
